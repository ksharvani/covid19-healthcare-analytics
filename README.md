# Covid19-healthcare-analytics. 
Data Analyst | SQL | Power BI | BigQuery | Excel

End-to-end healthcare analytics project using Google BigQuery SQL and Power BI to analyze COVID-19 cases, deaths, recoveries, hospitalizations, ICU patients, and vaccination trends.

**COVID-19 Healthcare Analytics Dashboard**
This project analyzes global COVID-19 data using Google BigQuery SQL and Microsoft Power BI. It explores case trends, deaths, recoveries, hospitalizations, ICU patients, and vaccination progress to support data-driven healthcare insights.

**Tools & Technologies**
  Google BigQuery: SQL queries, data validation, aggregations, window functions, and analytical metrics
  Microsoft Power BI Desktop: Interactive dashboards, data modeling, DAX measures, and visual analytics
  Power Query: Data transformation and preparation
  Data Modeling: Fact and dimension tables with a star-schema approach
 
**Dataset**
Source: Google BigQuery public dataset — _bigquery-public-data.covid19_open_data.covid19_open_data_
The project focuses on country-level data over time.

**Key Analysis Areas**
COVID-19 confirmed cases and deaths
Monthly case trends and month-over-month changes
Seven-day rolling averages
Case fatality rate (CFR)
Vaccination progress and country comparisons
Recovered patients, hospitalizations, and ICU patient trends
Country rankings and comparative performance

**Power BI Report**
The report contains five analytical pages covering overall trends, monthly analysis, country comparisons, vaccination progress, and advanced country-level performance.
Dashboard screenshots will be added here.

**SQL & Analytics Skills Demonstrated**
Aggregations, joins, CTEs, and window functions
LAG() and rolling-average calculations
Data quality checks and null analysis
DAX measures and interactive report filtering
Fact/dimension modeling and report performance analysis
Row-level security (RLS) configuration and testing in Power BI Desktop

**Project Goals**
To demonstrate practical skills in SQL-based analytics, data modeling, business intelligence, and communicating insights through interactive dashboards.
