Power BI Dashboard

This folder documents the Power BI report developed for the COVID-19 Healthcare Analytics project.

**Report Features**
_Five analytical report pages_
Interactive country, year, month, quarter, and date filters
KPI cards for confirmed cases, deaths, vaccination percentage, and case fatality rate
Monthly trends and month-over-month analysis
Country comparisons and rankings
Recovered patient, hospitalization, and ICU analysis
DAX measures for analytical calculations
Data modeling using fact and dimension tables
Row-level security (RLS) configuration and testing
Implementation

The report uses Power BI Desktop in Import mode, with Google BigQuery as the data source.

Dashboard screenshots and selected DAX measures will be added to this folder.
